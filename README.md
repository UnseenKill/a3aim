A3AIM
=====

**Arma ]|[ mod - Intercept Munitions**

[![pipeline status](https://gitlab.perfect-co.de/arma3/a3a-intercept-munitions/badges/dev/pipeline.svg)](https://gitlab.perfect-co.de/arma3/a3a-intercept-munitions/-/commits/dev)
[![Latest Release](https://gitlab.perfect-co.de/arma3/a3a-intercept-munitions/-/badges/release.svg)](https://gitlab.perfect-co.de/arma3/a3a-intercept-munitions/-/releases)

This Arma 3 mod allows CRAM/SAM to take down artillery/mortar shells, MLRS 
rockets and bombs.

Features
--------

This *server-side only* mod makes projectiles shot by artillery/mortar, rocket
launchers or dropped bombs trackable for anti-air systems like Patriot or the
Praetorian.

Installation
------------

### Sources

A3AIM is available at [my personal gitlab][gitlab-a3aim].

### Building

#### Prerequisites

In order to get working .pbos out of source codes, you'll need:

* Arma 2.20
* [Arma 3 Tools][arma-tools]
* [Git][git]
* [HEMTT][hemtt] - An opinionated build system for Arma 3 mods
* Sources from [here][gitlab-a3aim]

#### Creating .pbos

The mod's .pbos are created with HEMTT; a casual `hemtt build` should do the trick.

Usage
-----

Nothing to do but load it as a server mod.
